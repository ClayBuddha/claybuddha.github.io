4.2 拓扑架构：前级整流（AFE/CHB）· 后级隔离（DAB/MFT）· 输出级

主流架构

三级式 CHB + ISOP-DAB + 逆变：10kV 中压标配

国网/南网示范工程与兆瓦级 SST 的唯一主流落地架构：级联 H 桥（CHB）有源前端整流完成单位功率因数整流与谐波治理 → ISOP-DAB 高频隔离完成电压变换与电气隔离 → 公共低压母线逆变/直流输出。两级直流母线强解耦，支持 PEBB 模块化、N+1 冗余、故障旁路不停机。星形接法可减少级联链节数量、降低 BOM，但对单模块载流能力要求极高。

来源：与非网 · 搜狐（倾佳电子） · 2026-06/07
隔离级选型

DAB 双有源桥：量产首选，20–60kHz 高频运行

DAB 原生双向功率流、调压范围宽、动态响应快，可复用变压器漏感实现 ZVS，双/三移相控制已工程化，峰值效率可达 97%+；头部企业 2.5MW SST 项目隔离级采用 DAB + 1200V SiC 模块（适配 1500V 系统、20–60kHz），转换效率达 99.3%。LLC 额定点效率最高但仅单向；CLLC 支持双向但调压窄。阳光 EnerNeo 采用「中压 AC-DC + DC-DC」两级架构，单相 6+3 冗余模块、热插拔在线运维。

材料层云路股份等纳米晶为 SST 高频变压器磁芯最优材料选择（Bsat 约 1.2T、高频低损耗）；国内已产出 12μm 以下极薄纳米晶带材，损耗再降 50%+；非晶铁心变压器已突破单机 10MVA
技术痛点50kHz 纳米晶 MFT 的直流偏磁饱和是核心工程难题：伏秒不平衡→磁通阶梯行走→励磁电流尖峰。业界采用二次谐波特征提取 + 非对称调制模型预测控制（AMCPC）主动补偿，并辅以驱动级硬保护；磁-热-流耦合设计+单相浸没式液冷可将满载热点温度较风冷降低 25°C；漏感需精确控制在 ±5% 以内，主流采用壳式磁芯+分段交错绕法、利兹线/铜箔绕组

4.4 保护器件：固态断路器（SSCB）/ SPD / EMI / CT

刚需增量

SSCB：800V 直流架构的保护刚需

800V 直流无过零点、短路电流上升极快，1.2kV SiC MOSFET 短路耐受仅 4–8μs，机械断路器（毫秒级）无法保护 → SSCB 微秒级分断（传感→检测→分断→MOV 能量吸收，全程 1 至数十 μs）、零电弧、寿命达机械式 100 倍。英伟达白皮书明确 800VDC 系统采用 SSCB 做配电回路保护；2MW SST 约 25–30 个 800V 低压模块互为备份，SSCB 把故障限制在单模块内。

配套器件

SPD / EMI / CT 与输出滤波

SSCB 能量吸收依赖 MOV（ZnO 压敏电阻）纳秒级钳位，将感性短路能量换流至 MOV 热耗散，钳位电压设计在 800–1000V（低于 1200V 器件雪崩极限）；两电平/高频拓扑对输入滤波与 EMI 设计、布局寄生参数要求显著提升；检测环节采用 Rogowski 线圈做 di/dt 极速监测（1μs 内确诊短路）；DAB 高频化同步驱动输出滤波电感/电容小型化，磁集成与 PCB 绕组平面变压器成为下一个效率战场。
